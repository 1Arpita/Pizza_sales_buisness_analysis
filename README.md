🍕 Pizza Sales Analysis using MySQL & Excel
📌 Project Overview

This project focuses on analyzing pizza sales data using MySQL and Microsoft Excel to uncover valuable business insights related to revenue, customer ordering behavior, product performance, and sales trends.

The project demonstrates an end-to-end data analysis workflow starting from database creation and SQL querying to dashboard creation and business reporting.

🎯 Business Problem Statement

The business generates large amounts of transactional sales data daily, but without proper analysis it becomes difficult to identify:

📈 Peak sales periods
👥 Customer ordering patterns
🍕 Best-selling pizzas
💰 Revenue-driving categories
📊 Product performance trends

The objective of this project is to analyze pizza sales data and create an interactive dashboard that supports data-driven business decision-making.

🚀 Project Objectives
💵 Analyze total revenue and sales performance
📅 Identify peak ordering days and hours
🍕 Understand customer preferences by pizza category and size
🏆 Identify top-performing and low-performing pizzas
📊 Create an interactive dashboard for reporting
💡 Generate business recommendations from sales insights
